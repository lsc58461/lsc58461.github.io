## 왜 만들었나

프리랜스 작업을 하다 보면 견적 요청에 응답하는 일이 계속 반복됩니다. 요청을 확인하고, 내용에 맞는 견적 문구를 쓰고, 보내는 흐름인데 — 매번 비슷하지만 매번 조금씩 다릅니다. 그래서 **조회부터 발송까지를 한 화면에 묶은** 데스크톱 앱을 직접 만들어 쓰고 있습니다.

## 구조

- **조회**: 브라우저를 띄우는 대신 HTTP 계약을 직접 다룹니다. 화면 구조가 바뀌어도 덜 흔들리고, 무엇보다 훨씬 가볍습니다.
- **초안 생성**: 요청 내용을 LLM(Gemini)에 넘겨 그 건에 맞는 견적 문구를 만듭니다. 템플릿을 돌려쓰는 게 아니라 요청마다 내용을 반영합니다.
- **검토 후 발송**: 생성된 문구는 **사람이 확인하고 고친 뒤에** 나갑니다. 전부 자동으로 흘려보내는 구조가 아닙니다.

Electron 셸 + Next.js 렌더러 조합이고, 설치형과 포터블 두 가지 exe로 빌드해 씁니다. 패키징 단계에서 실행 파일 리소스에 아이콘을 주입하는 후처리도 붙였습니다.

## 만들면서 남은 것

자기 업무를 자동화하는 도구는 요구사항이 계속 바뀌기 때문에, 조회·생성·발송을 각각 갈아끼울 수 있게 나눠두는 게 결과적으로 이득이었습니다. LLM 제공자를 바꾸거나 문구 전략을 손볼 때 나머지를 건드리지 않아도 됩니다.
