## 무엇을 했나

"검색해서 나오는 대상의 연락처/이메일을 대량으로 모아 엑셀로 달라"는 유형의 의뢰를 여러 건 수행했습니다. 공통 구조는 **검색 → 사이트 방문 추출 → 정규화 → 엑셀**의 파이프라인입니다.

- **이메일 수집**: Serper.dev로 SERP URL을 모으고, 각 사이트의 홈·연락처 페이지를 방문해 mailto·본문·`[at][dot]` 난독화까지 복원해 추출합니다. 다수 사이트 방문 시 차단을 피하려 ISP 프록시를 붙였습니다.
- **지도 장소 수집**: 네이버 지도 pcmap의 GraphQL 엔드포인트와 서명 헤더(`x-wtm-graphql`)를 재현해 장소 데이터를 수집했습니다. 확률적으로 뜨는 캡차는 재시도로 흡수했습니다.
- **공공 데이터 덤프**: 검색 파라미터조차 없던 공개 공장 데이터 API를 분석해 전국 85만 건을 전량 덤프했습니다.

## 정직한 실측

가장 중요한 기여는 종종 **"이 데이터는 여기까지가 상한"**임을 먼저 밝히는 것이었습니다. 예컨대 대량 주소로 관리사무소 연락처를 수집하는 건에서, 샘플이 공장·학교·관공서 위주라 관리사무소라는 조직 자체가 2%뿐이라는 걸 실측으로 확인하고, 부풀린 기대 대신 현실적인 수집률과 파일럿 분리 견적을 제안했습니다.
