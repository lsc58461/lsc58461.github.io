## 무엇을 했나

지자체·시설관리공단이 운영하는 여러 예약 사이트에서, 선착순으로 열리는 대관 슬롯을 오픈 순간 확보하는 자동화 프로그램들입니다. 사이트마다 스택과 방어 수준이 달라 각각 분석해야 했습니다.

- **무방어 REST 사이트**: 로그인·CSRF·캡차가 전혀 없어 예약 JSON 한 번으로 완료되는 곳도 있었습니다. 이 경우 관건은 서버 시계와 클라이언트 시계의 오차를 측정해 **오픈 규칙(예: 25일 10시)에 정확히 맞춰 쏘는 것**이었습니다. 오픈 규칙 자체를 노출하는 엔드포인트를 찾아 파라미터를 확정했습니다.
- **본인인증 로그인 사이트**: 휴대폰 본인인증·간편인증만 지원해 headless 로그인이 불가능한 곳은, Playwright로 사용자가 직접 로그인한 세션 쿠키를 인계받아 이후를 자동화하는 반자동 구조로 설계했습니다.
- **보안문자**: 자동 예약 방지 문자는 OCR로 처리하고, 페이지 골격은 EUC-KR인데 동적 라벨만 UTF-8 바이트가 섞여 들어오는 인코딩 함정까지 맞춰 파싱했습니다.

실제 예약을 유발하는 최종 제출 단계는 테스트에서 실행하지 않는 원칙으로, 조회·파싱·타이밍 로직을 오프라인/라이브 케이스로 검증해 납품했습니다.
