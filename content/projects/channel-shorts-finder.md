## 무엇을 만들었나

관심 있는 채널 수십 개의 쇼츠 영상을 전부 모아두고, 제목과 설명을 가로질러 검색하는 윈도우 데스크톱 앱입니다. 특정 주제가 어느 채널에서 다뤄졌는지 빠르게 찾는 용도입니다.

## 핵심 — API 쿼터 설계

YouTube Data API는 하루 쿼터가 정해져 있고, 검색 호출(`search.list`)은 100유닛으로 매우 비쌉니다. 채널 수십 개를 2년치 수집하려면 이 설계가 전부였습니다.

- 검색 호출을 아예 안 쓰고, 채널의 **쇼츠 재생목록**을 `playlistItems.list`(50개당 1유닛)로 넘긴 뒤 `videos.list`로 길이·조회수를 받는 경로로 바꿨습니다. 실측 **50개당 약 2유닛** — 검색 호출 대비 수십 배 절감.
- 전체 수집은 백필 토큰을 저장해 **쿼터가 소진되면 다음 날 이어받고**, 갱신은 새 영상이 없는 지점에서 멈추되 최근 영상의 조회수만 다시 측정합니다.
- 실측: 15개 채널 12,210개 영상을 140초/519유닛에 수집, 갱신은 6초/24유닛.

## 검색 엔진

단순 LIKE가 아니라, 한글 **초성 검색**(ㄱㄷㅇ → 음절 범위 정규식), 글자 사이 공백 무시, 내장 약어 사전 + 사용자가 추가하는 동의어 묶음까지 지원합니다. WASM SQLite에 커스텀 함수를 등록해 12,000행을 70~110ms에 매칭하고, 하이라이트도 같은 규칙으로 표시합니다. 네이티브 빌드가 없어 설치·배포가 가볍습니다.
